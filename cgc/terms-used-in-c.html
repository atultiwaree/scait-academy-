C Character sets

Before learning C we should know frequently used terms in C such as character sets, constants, variables and keywords

Here we will only learn about character set, for the rest goto menubar.

The C character set

A character stand for any special symbol, alphabate or digits used to display Information

See the table representing valid alphabate, numbers and special symbols allowed in C.


Alphabets A, B,...,Z
a,b,...z
Digits 1,2,3,4,5,6,7,8,9
Special Symbols ~!@#$%^&*()_+=-|{}[];:"'?/|&<&tt;

Example

//Special Characters
 char a[40] = "~!@#$%^&*()_+=-|{}[];:'?/|&<&tt;";
 //Alphabates
 char b[20] = "CGC Landran";
 //Numbers
 int c = 20;
 //Printing Characters on Screen
 printf(" %s \t", a);
 printf(" %s \t",b);
 printf(" %d",c);
