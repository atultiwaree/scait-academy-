Comments in C

Comments are the entries in program for the purpose of documentation also to explain what each block of the program is doing, these statements are Ignored by Compiler

Types of Comments

  1. Single line Comments
  2. Double line Comments

Single Line Comments

Single-line comments start with two forward slashes (//).

Example

//I will Disappear
 printf("1 line will disappear on Output");

Run On Compiler

After forward slashes it only hides single line


Multi Line Comments In C

Multi-line comments start with /* and ends with */.

Example

/* These
three lines
will disappear */
 printf("3 lines dissapear on Output");

Run On Compiler

All the words written between /*... */ are being Ignored
