C Introduction

C is a Procedural structure-oriented, middle-level programming language used to develop low-level applications.

or

A programmning language, having virtues of high-level programming languags(mainly machine independent) and efficiency of assembly languages.

Why to learn C Today ?

  • to have a good hold over basic programming skills
  • to closely interact with hardware of devices
  • to make computer games faster
  • to write device driver programs because major parts of OS such as windows, UNIX, linux and android are written using C
  • for writing programs which is should run fast and have to be written in very less memory ex:microwave, washing machine and digital cameras.
  • for writing your own OS

History and Facts of C

  1. C was Developed and Released on 1972 by Dennis Ritchie at Bell Laboratories
  2. C language is the first high-level programming language.
  3. C is a structured programming language which which means we can break and write complex program into simple programs called functions.
  4. Many programming languages are made using C lanuage
